# Contribuir a FraterChrist.org

¡Gracias por ayudar! Queremos que participar sea sencillo, respetuoso y útil para el proyecto.

## Antes de empezar

- Lee la visión y el alcance en el [README](README.md).
- Consulta el [roadmap](docs/ROADMAP.md) y la [arquitectura propuesta](docs/ARCHITECTURE.md).
- Revisa el [Código de conducta](CODE_OF_CONDUCT.md).
- Busca Issues existentes para evitar duplicar trabajo.

## Proponer cambios

Para cambios funcionales o técnicos, abre una Issue describiendo el problema, el valor para las personas usuarias, una solución posible y los criterios de aceptación. Las correcciones pequeñas de documentación pueden proponerse directamente mediante pull request.

No des por aprobada una tecnología o funcionalidad porque aparezca en el roadmap: las propuestas pueden cambiar al validarse.

## Flujo de trabajo

1. Crea una rama a partir de main, por ejemplo feat/feed-pagination o docs/roadmap.
2. Mantén el cambio enfocado y evita combinar varias funcionalidades sin relación.
3. Añade o actualiza pruebas cuando cambie el comportamiento.
4. Ejecuta las comprobaciones disponibles y explica si alguna no pudo ejecutarse.
5. Abre un pull request con contexto, cambios, pruebas y capturas cuando ayuden a revisar la interfaz.
6. Responde a la revisión y actualiza la documentación afectada.

No subas contraseñas, tokens, archivos de entorno reales, datos personales de usuarios ni contenido privado.

## Convenciones

- Usa nombres de variables, funciones, clases y endpoints en inglés.
- Escribe documentación clara; inicialmente se mantiene en español y se aceptan contribuciones en español o inglés.
- Prefiere soluciones simples, mantenibles y probadas a abstracciones anticipadas.
- No añadas dependencias sin explicar qué necesidad cubren.
- Respeta la licencia GPL-3.0 y el [Código de conducta](CODE_OF_CONDUCT.md).

El repositorio está en una etapa temprana. Las primeras contribuciones más útiles pueden ser documentación, revisión de requisitos, accesibilidad, pruebas y pequeñas mejoras al entorno de desarrollo.
