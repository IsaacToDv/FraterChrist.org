# Reportar vulnerabilidades

La seguridad y la privacidad de la comunidad son prioritarias.

**No publiques en una Issue abierta contraseñas, tokens, información personal ni instrucciones que permitan explotar una vulnerabilidad.**

Si GitHub muestra la opción **Report a vulnerability** en la pestaña Security del repositorio, utiliza ese canal privado. Si no está disponible, contacta al mantenedor mediante su perfil de GitHub y comparte solo la información mínima necesaria para iniciar una conversación privada.

Incluye, cuando sea posible:
- Componente afectado y versión/commit.
- Impacto observado y condiciones necesarias para reproducirlo.
- Una forma segura de verificar el problema.

No intentes acceder a datos de otras personas ni realizar pruebas destructivas. El equipo confirmará la recepción, evaluará el impacto y coordinará una corrección antes de publicar detalles técnicos.
